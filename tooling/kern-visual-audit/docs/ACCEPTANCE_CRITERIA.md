# Acceptance Criteria

- Create project and run.
- Upload desktop/mobile privately.
- Preserve originals.
- Segment long screenshots.
- Validate inputs with actionable errors.
- Generate page map and separate specialist audits.
- Validate findings against schema.
- Display evidence, scorecard and AI fingerprint.
- Approve/reject findings and create lots.
- Generate three prompts per lot.
- Export JSON, Markdown and HTML.
- Create verification runs and classify every P0/P1.
- Enforce final verdict gates.
- Retry phases without duplicates.
- Deny cross-tenant access.

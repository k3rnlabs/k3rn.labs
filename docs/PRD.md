# PRD — KERN Visual Audit

## Product

A KERN Labs sub-SaaS that converts landing-page evidence into an actionable and verifiable quality pipeline.

## Problem

Founders and vibe coders can generate polished landing pages quickly but often cannot determine why the page feels AI-generated, whether mobile is coherent, whether positioning is clear, which issues matter first, which skills/prompts to use, or whether corrections worked.

## Value proposition

Upload desktop and mobile captures. Receive a rigorous visual/CRO/technical audit, evidence-linked findings, a scorecard, an AI-fingerprint analysis, implementation lots, exact prompts and before/after verification.

## Primary user

Solo founder or small product team using Codex, Claude Code, Cursor, v0, Lovable, Bolt, Replit or similar tools.

## MVP

- projects and audit runs;
- private desktop/mobile upload;
- segmentation;
- structured specialist passes;
- findings and scorecard;
- prompt packages;
- JSON/Markdown/HTML export;
- new captures and verification.

## Non-goals

- autonomous code modification in MVP;
- Figma replacement;
- guaranteed conversion uplift;
- AI authorship detection;
- synthetic testimonials;
- universal aesthetic ranking.

# UI/UX Specification

Direction: Shadcn neutral/grey, restrained, evidence-first, no decorative AI gradients and no card monoculture.

## Screens

1. Projects.
2. New audit run.
3. Run progress timeline.
4. Results tabs: Overview, Desktop, Mobile, AI Fingerprints, Positioning, Images, Technical, Roadmap, Prompts, Before/After.
5. Finding detail with evidence, impact, recommendation, skill, effort and verification.
6. Prompt package with install commands.
7. Before/after verification.

## Accessibility

Keyboard complete, visible focus, semantic tabs, no color-only status, descriptive evidence alt text, scrollable mobile tables, 44px touch targets and reduced motion.
